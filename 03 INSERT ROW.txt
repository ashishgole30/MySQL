3. Create a table
4. Select that table

To insert row into a table
(comma separated data for each coloumn)
statement:
INSERT INTO tablename
VALUES(,);

example:
INSERT INTO employees
VALUES (1,"Eugene","Krabs",25.50,"2023-01-02");
SELECT * FROM employees;

Inserting mutliple rows at once:
INSERT INTO tablename
VALUES(),(),(),();
example:
INSERT INTO employees
VALUES
(2,"Squidward","Tentacles",15.50,"2023-01-03"),
(3,"Spongebob","Squarepants",18.00,"2023-01-04"),
(4,"Patrick","Star",35.50,"2023-01-05"),
(5,"Sandy","Cheeks",22.50,"2023-01-06");
SELECT * FROM employees;
