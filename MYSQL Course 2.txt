1.  WHERE Clause
Used to filter/select specific rows.
| Operator | Meaning       |
| -------- | ------------- |
| =        | Equal         |
| >        | Greater than  |
| <        | Less than     |
| >=       | Greater/equal |
| <=       | Less/equal    |
| !=       | Not equal     |

Syntax: SELECT * FROM table_name
        WHERE (condition)
Example: SELECT * FROM students
         WHERE marks > 80;
Example: SELECT * FROM students
         WHERE id = 1;
Example: SELECT * FROM students  
         WHERE marks < 80;

2. UPDATE
Used to modify existing data.
Syntax: UPDATE table_name
        SET coloumn = (something)
        WHERE coloumn = (something);
Example: UPDATE students
         SET marks = 95
         WHERE id = 2;
NOTE: Always use WHERE in UPDATE.
Example:    UPDATE students
            SET marks = 95
            WHERE id = 2;
